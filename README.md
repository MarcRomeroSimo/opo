# Quadern · Parlament C1

Client web amb entrada restringida, aprovació de Mrs i progrés individual a Supabase.

Aquest repositori només conté el client públic. El temari i les preguntes es desen al contenidor privat de Supabase i el servidor autoritza cada petició.

La clau publicable d’auth-config.js és pública per disseny; no s’hi han d’afegir claus secretes, service_role, contrasenyes ni dades d’usuaris.

La vinculació correspon a una IP pública i un identificador de navegador. No acredita un dispositiu físic. El primer accés aprovat vincula el compte; Mrs pot desbloquejar-lo des d’Administració.

El material d’estudi i les preguntes enllacen les fonts oficials corresponents. No és una publicació del Parlament de Catalunya.
